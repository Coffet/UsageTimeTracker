## Design Context

### Users
People reviewing their own application usage in a local-first desktop tracker.
They need readable time blocks, application totals, recent activity, and a
useful heatmap without sharing their data.

### Brand Personality
Simple, artistic, and quiet. The interface should feel carefully composed
rather than like a generic AI-generated dashboard.

### Aesthetic Direction
Use an original composition with horizontal navigation, a prominent live
clock, practical time blocks, and readable tables in both themes. Avoid
imitating reference layouts, gradients, flashy motion, and excessive visual
noise. Use the platform's standard system font consistently.

### Design Principles
- Make activity and foreground-only accounting clear and truthful.
- Keep optional controls out of the way until needed.
- Match controls and dialogs to the active theme.
- Preserve readable contrast and keyboard navigation.
- Use local data and respect privacy.
